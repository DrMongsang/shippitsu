# Google Apps Script データコピースクリプト

スプレッドシート間でデータを安全かつ確実にコピーするための Google Apps Script です。

## 主な機能

### ✅ 安定性向上の特徴

1. **自動再開機能**
   - 実行時間制限（5分）に達した場合、自動的に1分後に続きから再開
   - チェックポイント機能により、処理済みの行数を保存
   - ネットワークエラーやタイムアウトからの自動復旧

2. **メモリ効率化**
   - チャンクサイズ: 100行（メモリ使用量を最小化）
   - 使用済みデータの即時解放
   - バッチ読み込みによるメモリ最適化

3. **レート制限対策**
   - 各操作後に待機時間を設定（800ms）
   - チャンク間に2秒の待機時間
   - SpreadsheetApp.flush() で確実に書き込み

4. **詳細なログとエラーハンドリング**
   - 進捗率と経過時間をリアルタイム表示
   - エラー発生時のスタックトレース記録
   - リトライ機能（最大3回、指数バックオフ）

## 使い方

### 基本的な実行

```javascript
// メイン関数を実行
copyVisitDataToMySheet_Stable();

// パフォーマンス測定付き実行
copyWithPerformanceMonitoring();

// 元データ更新時のみ実行（11:30以降）
copyIfSourceUpdated();
```

### デバッグ・メンテナンス関数

```javascript
// ヘルスチェック（接続とアクセス権限の確認）
healthCheck();

// 現在の処理状態を確認
checkStatus();

// チェックポイントをリセット（最初からやり直し）
resetCheckpoint();

// 自動再開トリガーをクリーンアップ
cleanupTriggers();
```

## トリガー設定

### 推奨トリガー設定

1. **定期実行トリガー**
   - 関数: `copyIfSourceUpdated`
   - 頻度: 15分ごと または 30分ごと
   - 効果: 元データが更新された場合のみコピーを実行

2. **手動実行用**
   - 関数: `copyWithPerformanceMonitoring`
   - 用途: 初回セットアップや手動での完全コピー

## 設定のカスタマイズ

スクリプト内の定数を変更することで、動作をカスタマイズできます：

```javascript
const CHUNK_SIZE = 100;          // 一度に処理する行数
const BASE_DELAY = 2000;         // チャンク間の待機時間（ミリ秒）
const OPERATION_DELAY = 800;     // 各操作後の待機時間（ミリ秒）
const MAX_EXECUTION_TIME = 300000; // 最大実行時間（5分）
const AUTO_RESUME = true;        // 自動再開を有効化
```

### チューニングのヒント

- **処理が途中で止まる場合**: `CHUNK_SIZE` を 50 に削減
- **データ量が少ない場合**: `CHUNK_SIZE` を 200 に増加、`BASE_DELAY` を 1000 に削減
- **レート制限エラーが出る場合**: `BASE_DELAY` と `OPERATION_DELAY` を増加

## トラブルシューティング

### 問題: 途中で処理が止まる

**解決策**:
1. `checkStatus()` を実行して現在の状態を確認
2. 次回実行時に自動的に続きから再開されます
3. 強制的に最初からやり直す場合は `resetCheckpoint()` を実行

### 問題: レート制限エラー

**解決策**:
1. `CHUNK_SIZE` を 50 に削減
2. `BASE_DELAY` を 3000 に増加
3. 時間をおいてから再実行

### 問題: 自動再開トリガーが残っている

**解決策**:
```javascript
cleanupTriggers(); // すべての自動再開トリガーを削除
```

## 注意事項

1. **スプレッドシートID**: `SOURCE_SPREADSHEET_ID` と `DEST_SPREADSHEET_ID` を正しく設定してください
2. **アクセス権限**: 両方のスプレッドシートへの読み取り・書き込み権限が必要です
3. **同時実行**: ロック機能により、同時実行は自動的に防止されます
4. **データの整合性**: コピー処理中は元データを変更しないでください
