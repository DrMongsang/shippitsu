# プロンプトの基礎

## はじめに

プロンプトとは、AI言語モデルに対して与える指示や質問のことです。適切なプロンプトを作成することで、AIからより正確で有用な回答を引き出すことができます。本記事では、効果的なプロンプトを作成するための基礎知識を解説します。

## プロンプトとは

プロンプトは、AIとのコミュニケーションにおける「入力」です。人間がAIに何をしてほしいか、どのような情報が必要かを伝えるための手段となります。プロンプトの質が、AIの出力の質を大きく左右します。

## 良いプロンプトの特徴

効果的なプロンプトには、以下のような特徴があります:

### 1. 明確性

曖昧な表現を避け、具体的で明確な指示を与えます。

**悪い例:**
```
何か面白いことを教えて
```

**良い例:**
```
プログラミング初心者向けに、Pythonで作れる面白いプロジェクトを3つ紹介してください。
各プロジェクトについて、難易度と所要時間の目安も含めてください。
```

### 2. 具体性

詳細な情報や制約条件を含めることで、期待する回答に近づけます。

**悪い例:**
```
メールを書いて
```

**良い例:**
```
取引先への会議延期を依頼するビジネスメールを作成してください。
以下の情報を含めてください:
- 会議の予定日: 12月5日
- 延期希望日: 12月12日
- 理由: 社内の緊急プロジェクト対応のため
- トーン: 丁寧でプロフェッショナル
```

### 3. 文脈の提供

背景情報や目的を伝えることで、より適切な回答が得られます。

**例:**
```
私はWebデザイン初心者で、初めてポートフォリオサイトを作ろうとしています。
HTMLとCSSの基本は理解していますが、JavaScriptはまだ学習中です。
レスポンシブデザインを実装する際の、初心者向けのベストプラクティスを教えてください。
```

### 4. 構造化

箇条書きや番号付きリストを使用すると、複数の要求を整理できます。

**例:**
```
以下の点について教えてください:
1. Git rebaseとは何か
2. Git mergeとの違い
3. どのような場合にrebaseを使うべきか
4. 使用時の注意点

それぞれ2-3文程度で簡潔に説明してください。
```

## 基本的なプロンプト技術

### ロールの指定

AIに特定の役割を与えることで、専門的な視点からの回答を得られます。

**例:**
```
あなたは経験豊富なPythonエンジニアです。
コードレビューの観点から、以下のコードの改善点を指摘してください。
```

### フォーマットの指定

出力形式を明確に指定することで、使いやすい形式で回答を得られます。

**例:**
```
以下の質問に対して、表形式で回答してください:

プログラミング言語「Python」「JavaScript」「Java」について、
- 主な用途
- 学習難易度
- 人気度
を比較してください。
```

### ステップバイステップの要求

複雑なタスクは、段階的に説明するよう求めることで理解しやすくなります。

**例:**
```
Reactで簡単なToDoアプリを作成する手順を、
初心者向けにステップバイステップで説明してください。
各ステップでは、何をするのか、なぜそれが必要なのかも含めてください。
```

### 例の提供（Few-shot Learning）

期待する形式の例を示すことで、より正確な出力が得られます。

**例:**
```
以下の形式で、プログラミング用語の説明を作成してください:

【例】
用語: API
読み方: エーピーアイ
正式名称: Application Programming Interface
説明: ソフトウェア間でデータや機能をやり取りするための仕組み
使用例: 「天気予報APIを使って、現在の天気情報を取得する」

では、以下の用語について同じ形式で説明してください:
用語: DOM
```

## プロンプト作成のベストプラクティス

### 1. 反復的な改善

最初のプロンプトで完璧な結果が得られないことは普通です。結果を見て、プロンプトを改善していきましょう。

### 2. 制約条件の明示

- 文字数や単語数の制限
- 使用する技術やライブラリの指定
- 避けるべき内容
- 対象読者のレベル

これらを明示することで、より適切な回答が得られます。

### 3. 出力の検証を促す

「説明に誤りがないか確認してください」など、AIに自己チェックを促すことで、より正確な回答を得られる場合があります。

### 4. 段階的なアプローチ

大きなタスクは小さく分割し、段階的に進めることで、より良い結果が得られます。

## 避けるべきこと

- **過度に短いプロンプト**: 情報不足で曖昧な回答になる可能性があります
- **複数の無関係なトピックを一度に**: 焦点がぼやけ、どの質問にも十分な回答が得られません
- **前提知識の欠如**: 必要な背景情報を提供しないと、的外れな回答になることがあります
- **矛盾する指示**: 「簡潔に」と「詳しく」など、矛盾する要求は避けましょう

## 実践例

### 例1: コード生成

**改善前:**
```
ログイン機能を作って
```

**改善後:**
```
Node.jsとExpressを使用した、基本的なログイン機能のコードを作成してください。
要件:
- ユーザー名とパスワードでの認証
- JWTトークンを使用したセッション管理
- パスワードはbcryptでハッシュ化
- エラーハンドリングを含める
- コメントで各部分の説明を追加
```

### 例2: 説明・学習

**改善前:**
```
REST APIって何?
```

**改善後:**
```
REST APIについて、プログラミング初心者向けに説明してください。
以下の点を含めてください:
1. REST APIとは何か（基本概念）
2. なぜ重要なのか
3. 日常的な使用例（具体的なサービス名を挙げて）
4. 基本的な操作（GET、POST、PUT、DELETE）
各項目は2-3文程度で、専門用語には簡単な説明を付けてください。
```

## まとめ

効果的なプロンプトを作成するための鍵は:

1. **明確で具体的な指示**を与える
2. **文脈や背景情報**を提供する
3. **期待する形式**を明示する
4. **適切な制約条件**を設定する
5. **反復的に改善**していく

これらの基礎を押さえることで、AIとのコミュニケーションがより効果的になり、求める結果を得やすくなります。プロンプトエンジニアリングは実践を通じて上達するスキルです。様々なプロンプトを試し、結果から学んでいきましょう。

## 参考リソース

プロンプトエンジニアリングについてさらに学びたい方は:

- 実際のタスクでプロンプトを作成し、結果を観察する
- 他の人のプロンプト例を参考にする
- フィードバックループを回し、継続的に改善する

プロンプトの作成は、技術というより「AIとの対話の技術」です。練習を重ねることで、自然と効果的なプロンプトが書けるようになります。
