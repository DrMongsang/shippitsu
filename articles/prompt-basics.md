# プロンプトの基礎

## はじめに

AIと話すとき、どう聞くかで返ってくる答えが全然違うって知ってました？

「プロンプト」っていうのは、要するにAIへの話しかけ方のことです。ちょっとしたコツを知っているだけで、AIから欲しい答えがグッと引き出しやすくなるんです。この記事では、そんなプロンプトの基本をわかりやすく解説していきますね。

## プロンプトって何？

プロンプトは、あなたとAIをつなぐ「橋」みたいなものです。

人間同士の会話でも、「ちょっと教えて」だけじゃ何を聞きたいのか伝わりませんよね？AIも同じで、具体的に伝えれば伝えるほど、的確な答えを返してくれます。

簡単に言うと：
- **プロンプトの質 = AIの答えの質**

これだけ覚えておけばOKです！

## 良いプロンプトの4つのポイント

効果的なプロンプトには、ちょっとしたコツがあります。難しくないので安心してくださいね。

### 1. はっきり伝える（明確性）

曖昧な聞き方だと、AIも困っちゃいます。

**うーん、これだとちょっと...**
```
何か面白いことを教えて
```

**これならバッチリ！**
```
プログラミング初心者向けに、Pythonで作れる面白いプロジェクトを3つ紹介してください。
各プロジェクトについて、難易度と所要時間の目安も含めてください。
```

違いがわかりますか？具体的に「何を」「どのくらい」「どんな形で」欲しいか伝えるのがポイントです。

### 2. 細かく指定する（具体性）

詳しく伝えれば伝えるほど、あなたが欲しい答えに近づきます。

**うーん、これだとちょっと...**
```
メールを書いて
```

**これならバッチリ！**
```
取引先への会議延期を依頼するビジネスメールを作成してください。
以下の情報を含めてください:
- 会議の予定日: 12月5日
- 延期希望日: 12月12日
- 理由: 社内の緊急プロジェクト対応のため
- トーン: 丁寧でプロフェッショナル
```

「誰に」「何のために」「どんな内容で」送るのかを伝えるだけで、使えるメールが返ってきます。

### 3. 背景を教える（文脈の提供）

「今の自分の状況」を伝えると、AIがあなたに合った答えを返してくれます。

**例えば:**
```
私はWebデザイン初心者で、初めてポートフォリオサイトを作ろうとしています。
HTMLとCSSの基本は理解していますが、JavaScriptはまだ学習中です。
レスポンシブデザインを実装する際の、初心者向けのベストプラクティスを教えてください。
```

「初心者です」と伝えるだけで、難しすぎる専門用語を避けた説明をしてくれるようになります。

### 4. 整理して聞く（構造化）

聞きたいことが複数あるときは、箇条書きにするとわかりやすいです。

**例えば:**
```
以下の点について教えてください:
1. Git rebaseとは何か
2. Git mergeとの違い
3. どのような場合にrebaseを使うべきか
4. 使用時の注意点

それぞれ2-3文程度で簡潔に説明してください。
```

番号を振るだけで、AIも「あ、4つの質問に答えればいいんだな」って理解してくれます。

## ちょっと上級な技

基本に慣れてきたら、こんなテクニックも試してみてください。

### 役割を演じてもらう

AIに「◯◯として答えて」とお願いすると、専門家っぽい視点で答えてくれます。

**例えば:**
```
あなたは経験豊富なPythonエンジニアです。
コードレビューの観点から、以下のコードの改善点を指摘してください。
```

「先輩エンジニアに見てもらってる」感じで、的確なアドバイスがもらえます。

### 形式を指定する

「こんな感じで答えて」って伝えると、使いやすい形で返してくれます。

**例えば:**
```
以下の質問に対して、表形式で回答してください:

プログラミング言語「Python」「JavaScript」「Java」について、
- 主な用途
- 学習難易度
- 人気度
を比較してください。
```

表にしてもらえると、パッと見て違いがわかって便利ですよね。

### 手順を追って教えてもらう

難しいことは、ステップに分けて説明してもらいましょう。

**例えば:**
```
Reactで簡単なToDoアプリを作成する手順を、
初心者向けにステップバイステップで説明してください。
各ステップでは、何をするのか、なぜそれが必要なのかも含めてください。
```

「1つずつ進めていけばできる」って思えると、難しいことも挑戦しやすくなります。

### 例を見せる（お手本を示す）

「こういう感じで答えてね」って例を見せると、めちゃくちゃ精度が上がります。

**例えば:**
```
以下の形式で、プログラミング用語の説明を作成してください:

【例】
用語: API
読み方: エーピーアイ
正式名称: Application Programming Interface
説明: ソフトウェア間でデータや機能をやり取りするための仕組み
使用例: 「天気予報APIを使って、現在の天気情報を取得する」

では、以下の用語について同じ形式で説明してください:
用語: DOM
```

フォーマットを揃えたいときに超便利です。

## 覚えておきたいコツ

### 最初から完璧を目指さない

一発で完璧なプロンプトを作るのは難しいです。でも大丈夫！

「うーん、ちょっと違うな」って思ったら、プロンプトを修正して再チャレンジ。これを繰り返すうちに、だんだんコツがつかめてきます。

### 制約を伝える

こんな情報を伝えると、より的確な答えが返ってきます：

- 文字数の制限（「300文字以内で」とか）
- 使いたい技術（「Reactを使って」とか）
- 避けたい内容（「専門用語は使わないで」とか）
- 誰向けか（「小学生でもわかるように」とか）

### チェックをお願いする

「説明に誤りがないか確認してください」って一言添えると、AIが自分で見直してくれることがあります。

### 大きなタスクは分ける

「Webサイト全部作って」じゃなくて、「まずトップページのHTMLを作って」みたいに、小さく区切って頼むのがおすすめです。

## やっちゃいけないこと

こんな聞き方は避けましょう：

- **短すぎる質問**: 「これ教えて」だけじゃ何が知りたいのかわかりません
- **一度に色々聞きすぎ**: 全部中途半端な答えになっちゃいます
- **背景を伝えない**: あなたのレベルや状況がわからないと、的外れな答えになることも
- **矛盾した指示**: 「簡潔に」と「詳しく」を同時に言われても困りますよね

## 実際にやってみよう

具体例で、ビフォーアフターを見てみましょう。

### 例1: コードを書いてもらう

**改善前（これだとちょっと...）:**
```
ログイン機能を作って
```

**改善後（これならバッチリ！）:**
```
Node.jsとExpressを使用した、基本的なログイン機能のコードを作成してください。
要件:
- ユーザー名とパスワードでの認証
- JWTトークンを使用したセッション管理
- パスワードはbcryptでハッシュ化
- エラーハンドリングを含める
- コメントで各部分の説明を追加
```

細かく指定すると、そのまま使えるコードが返ってきます。

### 例2: 何かを教えてもらう

**改善前（これだとちょっと...）:**
```
REST APIって何?
```

**改善後（これならバッチリ！）:**
```
REST APIについて、プログラミング初心者向けに説明してください。
以下の点を含めてください:
1. REST APIとは何か（基本概念）
2. なぜ重要なのか
3. 日常的な使用例（具体的なサービス名を挙げて）
4. 基本的な操作（GET、POST、PUT、DELETE）
各項目は2-3文程度で、専門用語には簡単な説明を付けてください。
```

聞きたいことを整理して伝えると、理解しやすい説明が返ってきます。

## まとめ

良いプロンプトを作るコツは、この5つだけ：

1. **はっきり具体的に**伝える
2. **背景や状況**を共有する
3. **欲しい形式**を指定する
4. **適度な制約**をつける
5. **試行錯誤**を恐れない

最初はうまくいかなくても全然OK。何度もやっているうちに、自然とコツがつかめてきます。

AIとの対話は、人と話すのとそんなに変わりません。「相手にわかりやすく伝える」ってことを意識すれば、誰でもすぐに上達できますよ。

## これからどうする？

プロンプトは、実際に使ってみるのが一番の勉強です：

- **とにかく試す**: 思いついたプロンプトをどんどん試してみましょう
- **人のマネをする**: 他の人が書いたプロンプトを参考にするのもアリ
- **振り返る**: 「この聞き方よかったな」「これはイマイチだったな」って記録しておくと上達が早いです

難しく考えなくて大丈夫。「AIに友達に説明するように話しかける」くらいの気持ちで、楽しみながらやってみてください！
